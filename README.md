📊 Mobile Store Sales Dashboard (Power BI)
This Power BI project showcases an interactive Mobile Store Sales Dashboard that visualizes sales performance across multiple dimensions such as city, mobile model, payment method, and customer ratings. The dashboard provides business insights into sales trends, customer behavior, and product performance.

🔍 Project Overview
Tool Used: Power BI

Domain: Retail / E-commerce

Data Source: Simulated transactional sales data

Primary Goal: To analyze and monitor mobile sales trends, transaction types, and customer satisfaction for strategic decision-making.

📌 Key Features
🔷 Main Dashboard (Current View)
Total Sales: ₹769M

Total Quantity Sold: 19K units

Total Transactions: 4K

Average Selling Price: ₹40.11K

Sales by City: Visualized using a geo-map across Indian cities.

Sales by Day Name: Bar chart analysis across the week.

Sales by Mobile Model: Comparative bar chart of top models like iPhone SE and OnePlus Nord.

Customer Ratings: Segmented into Good, Average, and Poor.

Transactions by Payment Method: Pie chart showing UPI, Debit, and Credit Card usage.

Quantity Sold by Month: Line chart trend across the year.

📅 MTD (Month-To-Date) View (Slide Available Separately)
Focuses on sales metrics for the current month.

Tracks early performance trends to take timely action.

📆 Same Period Last Year (Slide Available Separately)
Enables year-over-year performance comparison.

Useful for seasonal trend analysis.

Use slicers to filter by brand, model, and payment method.

Analyze monthly trends, performance by location, and user satisfaction.

Top Model: iPhone SE (₹60M in sales).
